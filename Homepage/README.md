# Homepage – Personal Website

A responsive, multi-page personal website built with HTML, CSS, JavaScript and Bootstrap. Part of [CS50x Week 8](..).

**Live site:** https://guilimati.github.io/CS50-week8/

## Pages

| File | Page |
|---|---|
| `index.html` | Home: introduction and links to the other pages |
| `about.html` | About: background and career direction |
| `journey.html` | Journey: my move from electrical engineering into technology |
| `contact.html` | Contact details and links |

## Features

- Shared Bootstrap navbar across all pages
- Responsive layout that works on mobile and desktop
- Custom styling in `styles.css`
- A JavaScript button (`script.js`) that shows a welcome message

## Tech stack

HTML5 · CSS3 · JavaScript · Bootstrap 5 · GitHub Pages
