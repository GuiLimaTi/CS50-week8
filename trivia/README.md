# Trivia – Interactive Quiz

A small quiz web app that checks answers and gives instant colour feedback using JavaScript. Part of [CS50x Week 8](..).

## Features

- Multiple-choice question: the clicked button turns green if correct or red if wrong
- Free-response question: the typed answer is checked when the user submits it
- Feedback message shown under each question

## How it works

JavaScript listens for clicks and form submissions (`addEventListener`), compares the answer with the correct one, and updates the page with `querySelector` without reloading.

## How to run

Open `index.html` in any browser.

## Tech stack

HTML5 · CSS3 · JavaScript
